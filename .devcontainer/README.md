# Sahbi Browser Codespaces

Open this repository in GitHub Codespaces. The devcontainer installs dependencies and starts Sahbi Browser on port 8080.

Important: configure SAHBI_TOKEN as a Codespaces secret before using the MCP endpoint. Never commit the token to the repository.

The forwarded port must be public for ChatGPT's remote MCP client to reach it. Stop the Codespace when not in use to preserve the included monthly compute quota.
